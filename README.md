# 🚀 Eedara Sai Deep | Developer Portfolio

A modern, high-performance portfolio website for **Eedara Sai Deep** – Backend & Full-Stack Developer, B.Tech Computer Science (Data Science) student at NIIT University. Built with **Next.js 16**, **React 19**, **Tailwind CSS v4**, **Framer Motion**, and **Three.js WebGL Fluid Simulation**.

## ✨ Key Features

- 🌊 **Fluid Splash Cursor**: Interactive WebGL fluid physics that responds to mouse and touch interactions.
- 🚀 **Smooth Inertial Scrolling**: Powered by **Lenis** for a refined, natural scroll experience.
- 🍱 **Modern Bento Layout**: Clean, organized sections for Projects, Experience, Education, and Skills.
- 🌓 **Dynamic Theme Engine**: Seamless Dark and Light mode switching with **next-themes**.
- ⚛️ **Framer Motion Animations**: Smooth transitions, staggered reveals, and scroll-triggered animations.
- ☁️ **Interactive 3D Skill Cloud**: 3D spherical mathematics rotating interactive skill cloud.
- 📱 **Fully Responsive**: Optimized for desktop, tablets, and mobile devices.
- 🔍 **SEO & Performance**: OpenGraph metadata, JSON-LD structured schema for developers, and Google Fonts optimization.

## 🛠️ Technical Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Core**: React 19, TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Interactions**: WebGL Fluid Simulation (Three.js shaders)
- **Scrolling**: Lenis
- **Icons**: Lucide React
- **Fonts**: Geist Sans & Outfit (Google Fonts)

## 🚀 Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the portfolio.

### 3. Push to GitHub
```bash
git remote add origin https://github.com/saideepeedara27-alt/<your-repo-name>.git
git push -u origin main
```
